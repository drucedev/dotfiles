Raw sources are the immutable source of truth. Read from them, quote them, and cite them, but never create, edit, move, delete, or reformat anything in the raw-source collection. Confine every write to the wiki layer (generated pages, index, and log) and, when explicitly agreed, the wiki's schema file. If a source appears wrong or outdated, record the discrepancy in the wiki rather than altering the source. If the boundary between raw sources and the wiki is unclear for a given knowledge base, ask before writing.
